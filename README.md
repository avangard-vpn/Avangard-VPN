# Avangard VPN 🛡️

Быстрый, стабильный и безопасный VPN-сервис для комфортной работы в сети.

## Особенности
* **VLESS Reality**: Самый современный протокол для обхода блокировок.
* **Стабильность**: Работает с банками, Госуслугами и Авито без необходимости отключения VPN.
* **Скорость**: Оптимизирован для просмотра YouTube в 4K.
* **Удобство**: Управление подписками и ключами прямо в Telegram-боте.

## Технологии
* Front-end: HTML, CSS (Glassmorphism design).
* Back-end: Marzban (Xray-core).
* Деплой: Vercel.

## Лицензия
Проект предназначен для личного использования и тестирования сетевых протоколов.
